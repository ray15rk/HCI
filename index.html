How GenAI Memory Works

Cross-Chat Memory allows the AI to securely connect symptoms you mention today with health patterns discussed in your past conversations.

When multiple symptoms match a common condition, the AI provides an insight card.

  • You can disable this at any time using the toggle in the sidebar.
  • When disabled, the AI isolates your current chat and will not reference past history.
